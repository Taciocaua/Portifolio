# Portfólio — Tácio Cauã

Portfólio pessoal desenvolvido para apresentar minha trajetória como estudante de **Análise e Desenvolvimento de Sistemas**, minhas habilidades técnicas e meus projetos na área de desenvolvimento de software.

O projeto foi desenvolvido com foco em uma interface **moderna, simples e responsiva**, buscando apresentar minhas informações de forma objetiva e proporcionar uma boa experiência de navegação.

## Acesse o projeto

🔗 **[Visualizar Portfólio](https://portifolio-sigma-livid.vercel.app/)**

## Sobre o projeto

Este portfólio foi criado como parte da minha jornada de aprendizado em desenvolvimento web.

A aplicação apresenta:

* Apresentação pessoal
* Informações sobre minha formação
* Tecnologias e habilidades
* Formas de contato
* Link para meu GitHub

O projeto também foi desenvolvido pensando em organização visual, semântica HTML e estilização utilizando CSS.

## Tecnologias utilizadas
